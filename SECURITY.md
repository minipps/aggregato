# Security reports

Report suspected vulnerabilities privately to **aggregato@dospuntostr.es**.
Please avoid public issues for details that could expose another installation.

Include the affected version or commit, deployment configuration, steps to reproduce,
and the impact you observed. Use synthetic records where possible and remove tokens,
cookies, personal history, and other private data from logs and attachments.

Reports are reviewed against the latest release and the current main branch. Support
for older releases and backports is assessed individually. A maintainer will coordinate
disclosure with the reporter after assessing the issue.
